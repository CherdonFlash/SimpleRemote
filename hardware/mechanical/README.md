- 主 PCB 外形约为 `98.263 × 66.650 mm`。
- PCB 到外壳平面坐标的变换为：`X壳 = Xobj - 21.122147`、`Y壳 = Yobj - 41.820067`。
- 校核装配体中 PCB 的 Z 偏移为 `+16.0 mm`，上壳装配偏移为 `+17.65 mm`。
- 上壳主体高度 `14.5 mm`，顶面和侧壁名义厚度均为 `2.0 mm`。

## 校验结果

- `遥控器上壳.SLDPRT` 在 SolidWorks 2024 中重建和保存结果为 `0 error / 0 warning`。
- 上壳为单一有效实体，外包络约 `102.264 × 70.649 × 15.700 mm`。
- 上壳特征树中包含 `SW13_Toggle_Left_Side_Opening_2026-08-11_OBJ`、`OLED_0p96_From_Header_Toward_TypeC` 和 `NRF24_Corrected_2026-08-11_Rear_Opening`；此前错误的 SW13 俯视面大孔已删除。
- 上下壳实体相交体数量为 `0`，相交体积为 `0 mm³`。
- 当前三件校核装配体的干涉检查返回 `interferenceCount=0`。
- OBJ 在 SolidWorks 中以图形体导入，适合位置和开孔的可视化校核，但不能代替实体 PCB 的制造级间隙分析；量产前仍应使用可形成实体的 STEP/Parasolid 再做一次精确干涉检查。

## 试制提示

- Type-C 为中置式接口，首件装配时应检查原底壳是否还需补充接口下半孔，并确认常用 Type-C 插头外壳可以完全插入。
- SW13 左侧槽已包含约 `2.14 mm` 的两档行程；首件应检查打印收缩、拨柄能否到达 ON/OFF 机械止点以及手指操作空间，必要时只沿拨动方向微调，不应在俯视面开孔。
- OLED 开口按用户提供的 `25.2 × 26.0 mm` 外形设计；实际模块的固定孔、玻璃偏移和排针焊接高度仍应在实物试装时复核。
- NRF24 模块和天线座按当前 PCB 位置伸出壳体顶部/后侧。若希望完全内置，需要同时加长外壳或修改 PCB 布局。
- 建议先打印一件 PETG/ABS 样件，重点检查 Type-C 插拔、SW13 行程、NRF24 模块间隙、定位舌松紧和螺钉底孔。
