## 系统结构

```text
USB-C 5V (+5V)
   │
   ├─ IP2312U (U3) 充电 ── 单节锂电池 VBAT (H5)
   │                             │
   │                             ├─ SW13 主电源开关 ── VBAT_ADC ── R39/R40 1:2 分压 ── PB1/BAT_ADC
   │                             │
   │                             └─ Q1 开关路径 ── FP6291 (U1) 升压输入
   │                                                │
   │                                        L1 + D1 升压输出 ── VOUT
   │                                                │
   └─ +5V ── D3 隔离二极管 ── VOUT（USB 与电池共同供电）
                                  ├─ RT9013 U25 ── 3V3（MCU、OLED、输入）
                                  └─ RT9013 U26 ── NRF24_3V3（无线模块）
```

> 注：SW13（SS12D06G5）位于**电池回路**（VBAT ↔ VBAT_ADC），是主电源滑动开关；USB 5V 与 FP6291 升压输出经 D3（SMA 二极管）隔离后共同产生 VOUT，再经两颗 RT9013 LDO 分别输出主系统 3V3 和无线模块 NRF24_3V3。

## 输入与外围电路

- 两个 3D161 摇杆分别提供两路模拟量，共四路 ADC 输入。
- IO1～IO4 各有 10 kΩ 上拉电阻（R35/R37/R34/R36）、100 nF 对地电容（C43/C45/C42/C44）和对地按键，符合固件使用浮空输入并按低电平判定按下的方式。
- SW2 的两端接 3V3 和 GND，中间端接 PA8，因此 PA8 不会在正常装配后悬空。
- BAT_ADC 由 R39/R40 两个 10 kΩ 电阻构成 1:2 分压，和固件 `bat.c` 中的 `scale = 2.0f` 一致。
- H1 是 OLED 接口，依次包含 GND、3V3、SCL 和 SDA；OLED 显示模组不直接焊接在原理图主板器件中。
- H2 是 SWD 接口，H3 是 USART1 调试接口，H5 是单节锂电池接口。

## 时钟、复位和启动配置

- X4 为 8 MHz 晶振，搭配 C48、C49 两个 22 pF 负载电容，对应固件的 HSE 8 MHz 和 PLL ×9 配置。
- NRST 使用 10 kΩ 上拉（R19）、100 nF 电容（C29）和复位按键（KEY1）。
- BOOT0 通过 R46 下拉，PB2/BOOT1 通过 R47 下拉，正常上电从主 Flash 启动。
- OSC32_IN/OSC32_OUT 没有安装低速晶振，当前固件也没有使用 LSE。

## 电源与设计检查

- USB-C 的 CC1、CC2 分别通过 5.1 kΩ 下拉（R2/R9），符合用电设备的电源识别方式。
- 主系统 3V3 和无线模块 NRF24_3V3 使用两颗独立 RT9013 LDO，有利于隔离无线发射造成的电源波动。
- 无线支路输出侧目前可见 100 nF 和 1 µF 去耦；E01-ML01DP5 发射时存在脉冲电流，打样前建议结合模块手册再次确认 LDO 余量、输出电容和模块附近的地平面。
- 网表中未见独立的电芯过充、过放保护芯片。若 IP2312U 不覆盖放电保护，应确认使用带保护板的单节锂电池。
- 32.768 kHz 晶振引脚悬空是当前设计选择；若未来启用 RTC，应补充 LSE 晶振及负载电容。
- PCB 已在顶层和底层设置 GND 铺铜。无线模块天线区域仍应在 EDA 中检查铜皮、走线和结构件净空。
- 电源开关 SW13 实测位于电池回路（VBAT ↔ VBAT_ADC），关闭后电池检测 ADC 将读到 0，升压输入也随之断开。

本分析基于导出的 EPRO 工程和 PCB 网表进行静态核对，不能替代嘉立创 EDA 的 ERC/DRC、实板电源测试及射频测试。
