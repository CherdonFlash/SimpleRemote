## 静态复核结果

- EPRO压缩工程结构完整，包含1张原理图和1块双层PCB。
- 工程包含91个器件位号、61个网络。
- 网表中的279项明确引脚—网络关系均能在PCB焊盘网络中找到，网络不一致数量为0。
- CW2015使用独立软件I2C（F103C6无硬件I2C2）：PB10/U23.21为SCL，PB11/U23.22为SDA。
- R57、R56分别将IIC2_SCL、IIC2_SDA通过4.7 kΩ上拉到3V3。
- 旧版PB1电池ADC及10 kΩ/10 kΩ分压已从当前原理图和PCB删除。
- CW2015外围与典型应用一致：CELL串470 Ω（R55），VDD串100 Ω（R54），两路各有1 µF电容。
- ALRT#当前不连接，软件每秒轮询读取。

以上是文件级静态检查，不能替代嘉立创 EDA 中实际执行ERC、DRC以及对最终Gerber的目视检查。

## 已确认的设计前提

- 项目不使用STM32的RTC后备电源功能，U23.1（MCU VBAT）按当前设计保持未连接；原始锂电池网络`VBAT`最高约4.2 V，不得接到该引脚。
- VDDA/VSSA滤波网络L6、L7是人工确认保留的设计。
- Q2在USB移除后通过`R17 → +5V公共节点 → R10 → R53`形成到GND的下拉路径，不是悬空栅极。
- 电池允许3 A充电，并且电池内部自带过充、过放、过流和短路保护板。
- 2026-09-12 已通过PB10/PB11软件I2C读取CW2015；已停止PB1电压兜底调用。参见[通信修复记录](CW2015通信修复记录.md)。

## 系统结构

```text
USB-C 5 V
   │
   ├─ IP2312U充电 ── 带保护板的1S锂电池 VBAT
   │                         │
   │                         ├─ CW2015电量计 ── 软件I2C/PB10/PB11
   │                         │
   │                         └─ SW13主开关 ── Q1/FP6291升压路径
   │                                                │
   └─ USB供电隔离路径 ───────────────────────────── VOUT
                                                    ├─ RT9013 U25 → 3V3
                                                    └─ RT9013 U26 → NRF24_3V3
```

## 投板输出检查

生成Gerber和下单前仍应在嘉立创EDA内完成：

1. 重新铺铜后运行ERC和DRC，确认未连接网络及错误数量为0。
2. 核对U27的1脚方向、中央散热焊盘、阻焊开窗和钢网开窗。
3. 核对D1、D2、D3、Q1、Q2、LED、电解电容和Type-C接口方向。
4. 检查NRF24天线区域的铜皮、走线、外壳和电池净空。
5. 用Gerber查看器复核板框、钻孔、铜层、阻焊层、丝印层和钢网层。
6. 确认BOM中的电感、电源芯片、二极管和MOS管型号与实际采购料一致。
